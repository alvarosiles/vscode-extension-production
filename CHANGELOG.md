# Changelog

Todos los cambios relevantes de este proyecto se documentan en este archivo.
El formato sigue [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/) y el proyecto usa [Versionado Semántico](https://semver.org/lang/es/).

## [1.0.0] - 2026-10-20

### Agregado
- Landing page con el catálogo de las 7 extensiones.
- Hero con ventana de VS Code animada.
- Tarjetas con filtros por categoría y modal con galería de capturas.
- Demo interactiva de atajos de teclado.
- Comando de instalación del pack con botón de copiar.
- Página 404, favicon, web manifest, `robots.txt` y `sitemap.xml`.
- Metadatos SEO, Open Graph, Twitter y JSON-LD.
- Deploy automático a GitHub Pages con GitHub Actions.
